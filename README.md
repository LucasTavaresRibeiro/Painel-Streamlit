# 🤖 Painel Streamlit — Planejamento, Cronograma & Horas RPA

Painel mobile-first em **Streamlit** para acompanhamento de cronograma, revisão/apontamento de horas e gestão de pendências dos projetos RPA:
- **Projeto CLT (`PRC_0100` — Corpo Clínico):** Prazo oficial de 4 meses (Nov/2026 a Fev/2027) com meta interna *Fast-Track* e controle de **76 horas**.
- **Projeto Horista (`FN027` — Intercompany):** Orçamento de **110 horas** (`R$ 50/h`) com marco de homologação (UAT) em **24/11/2026**.

## 🚀 Como publicar gratuitamente no Streamlit Cloud

1. Acesse [share.streamlit.io](https://share.streamlit.io)
2. Selecione este repositório público (`LucasTavaresRibeiro/Painel-Streamlit`)
3. Branch: `main`
4. Main file path: `app.py`
5. Clique em **Deploy!**
